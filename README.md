I'm currently exploring the intersection of **Enterprise Software + Generative AI**.

Building applications that combine:

```text
Enterprise Data
      ↓
Documents / APIs / Databases
      ↓
Embedding & Vector Store
      ↓
RAG Pipeline
      ↓
LLM
      ↓
Grounded Response
```

* Databases

* Documents

The goal is to move from simple **"chat with an LLM"** applications toward useful **AI-powered enterprise agents**.
